Даннк=ая программа предназначена для создание нескольких вариаций ip адресов из списка заданных и вывода их в отдельный файл.

для работы программы её необходимо скомпилировать.
для этого необходимо наличие на ПК "g++"(или иного компилятора) и "bash" и соответственно доступа к ним.

  способ №1 
1)скачать все 3 файла 
2) в командной строке ввести "chmod ugo+x instal.sh"
3) запустить сам файл "instal.sh" (можно 2 кликом мышки или же в консоль ввести  "./instal.sh"
4) при удачной компиляции будут созданы файлы запуск программы будет производиться с помощью файла "run"

  способ №2 
1) скомпилировать файл "main.cpp" любым компиляьтором для с++
2) запустить уже созданый вами файл

                                                                                            !!!Важно!!!
                                                                                            
даннная программа работает только на операционной системе linux на другий ОС функционированиие скорее всего не возможно 

                                                                                        Работа программы:

вы подаете на вход n-ip адресов далее будет созданна папка с файлом-результатом ,а также файл с вашим вводом(котой в конце программы можно будет либо удалить либо оставить). Оба файла с расширением .txt
в файле-результате будет содержаться n*84 >= новых ip адресов в нестандартнов виде(по 84 новых ip на каждый расспознаный ардрес)
формат для ip адресов представлен в файле "key.txt", если вам необходимы только определеные то можете оставить только их
